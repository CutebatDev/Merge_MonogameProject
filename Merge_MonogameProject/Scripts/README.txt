
    Merge MonoGame Project

A merge-style game built with MonoGame where players merge robots to create more powerful evolutions and manage resources.

    Goal of the Game

The objective is to strategically merge robots of the same type to create stronger evolutions while managing
 your economy (gears) to continuously expand and optimize your robot collection.

    Core Mechanics

- Merging System: Combine identical robots to create more advanced evolutions
- Resource Management: Earn and spend gears to purchase new robots
- Robot Evolution: Progress through different robot tiers by merging
- Economy System: Generate income through robot activities
- Grid-based Placement: Strategic positioning of robots on a game grid

    Controls

- Mouse: Primary interaction method for selecting, dragging, and merging robots
- Click: Select robots and UI buttons
- Drag & Drop: Move robots around the game grid
- UI Interactions: Navigate menus and adjust settings

    Gameplay

1. Start: Begin with basic robots and limited gears
2. Purchase: Buy new robots using your gear currency
3. Place: Position robots on the available grid spaces
4. Merge: Drag identical robots together to create evolutions
5. Earn: Collect gears generated by your robot collection
6. Expand: Use earnings to buy more robots and create stronger evolutions

    Core Classes & Responsibilities

 Game Management
- `Game1.cs`: Main game loop, initialization, and core game state management
- `Program.cs`: Application entry point
- `SceneManager.cs`: Handles different game scenes and transitions

 Game Objects
- `MergeObject.cs`: Base class for mergeable robots with core merge logic
- `RobotTag.cs`: Robot identification and properties system
- `RobotEvolutions.cs`: Defines robot evolution chains and upgrade paths

 Managers
- `SpriteManager.cs`: Centralized sprite rendering and management
- `EconomyManager.cs`: Handles gear currency and economic transactions  
- `RobotSpawnManager.cs`: Controls robot creation and spawning logic
- `ObjectPoolManager.cs`: Optimizes performance through object pooling
- `SoundManager.cs`: Audio playback and sound effect management

 UI System
- `UiButton.cs`: Interactive button components
- `CreateRobotButton.cs`: Specialized button for robot purchasing
- `GearCounterUI.cs`: Displays current gear currency
- `MusicSlider.cs`: Audio volume control slider
- `FloatingTextAnimator.cs`: Animated text effects for feedback

 Core Components
- `Sprite.cs`: Basic sprite rendering and properties
- `Spritesheet.cs`: Handles sprite animation and frame management
- `StringSprite.cs`: Text rendering system
- `Collider.cs`: Collision detection for game objects

 Economic System
- `Economy.cs`: Core economic rules and calculations
- `EconomyManager.cs`: Economic state management and transactions
